PURPOSE

우리가 함께 만들어가는 학교

일관된 생활지도가 만들어내는 세 가지 변화

자기 관리 역량

바른 생활습관 형성을 통해 스스로를 관리할 줄 아는 인재로 성장하도록 돕습니다.

학습권 보장

모든 학생의 학습권을 지켜, 안전하고 안정적인 학교 분위기를 함께 만들어 갑니다.

수업권 보장

성실히 준비한 수업을 온전히 구현하여, 교사의 자존감과 보람을 높입니다.

HOW TO USE

단 4단계면 충분합니다

구글 앱스크립트 연동으로 입력부터 통계까지 자동으로

01
설정

최초 1회 설정

설정 탭에서 교사 이름과 이메일을 한 번만 입력합니다.

02
빠른 입력

이름만 입력

'빈자리 입력 탭'을 열고 학생 이름만 입력 — 최대 10건 동시 입력.

03
자동 전송

기록 저장

앱스크립트가 데이터를 통계 시트로 이전하고 입력칸을 비웁니다.

04
조회 · 통계

검색하고 확인

통계 파일에서 학생 이름을 검색해 추이와 누계를 확인합니다.

SETUP & USAGE

초기 설정과 기록 입력, 따로 안내합니다

처음 한 번의 설정과 매일의 기록 입력을 구분해 익혀 보세요

STEP 01 · 설정

초기 설정하는 방법

1

설정 탭을 열어 교사 이름과 이메일을 최초 1회 입력합니다.

2

최초 사용 시 안내되는 앱스크립트 권한 허용을 완료합니다.

STEP 02 · 입력

기록 입력하는 방법

1

메뉴에서 빈자리 입력 탭을 열고 학생 이름만 입력합니다. (최대 10건)

2

기록 저장을 누르면 통계 시트로 자동 전송되고 입력칸이 비워집니다.

보안

개인정보 보호 필수

학생 개인정보 보호를 위해 통계 시트의 학생 노출 및 인쇄·저장 등 반출을 절대 금지합니다.

권한

최초 권한 허용

자동화 시스템(앱스크립트)의 원활한 작동을 위해 최초 사용 시 권한 허용이 필수입니다.
